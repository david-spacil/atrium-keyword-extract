## 🧭 Where it stands — 2026-11-06

### What the issue asks

- **The method:** a decision model picks the line's category by walking down the vocabulary. At each step it returns
  a probability for every option and writes no text.

| Level | Question                                                                                       |
|-------|------------------------------------------------------------------------------------------------|
| L0    | yes/no: is the marked line archaeological content? (no → `Nerelevantní (meta-text)`)           |
| L1    | the facet, + `none_of_these`                                                                   |
| L1g   | yes/no: is it really about a place, a people or a dynasty? (only for the guardrail's branches) |
| L2    | the facet's group, + `none_of_these` (skipped for one-group facets)                            |
| L3…   | the node's children, + `<this term>` where the node is a term, + `none_of_these`               |

- **The beam:** k = 3 at p ≥ 0.2. The answer is the best path ending in a term. If every path ends in
  `none_of_these`, the line is unresolved, as D2 asks.
- **The tree:**
  - 4,711 terms plus the meta-text sentinel;
  - 797 inner nodes are terms themselves;
  - up to 11 levels below a group.
  - Only `historické oblasti a státní útvary` (~260 children) exceeds the 255 options of a choice, and it is chunked.
- **Why it fits #2:**
  - no forced labels by construction (`zvonice`, `prahory` cannot come out);
  - a probability per option;
  - the whole vocabulary is reachable. The 58,260-token prompt reaches ~1,100 terms at a 16k window.
- **The comparison isolates the method:** Clef is built on Qwen3.8-27B, the backbone of the default `qwen-3.8-27b-it`.
- **What it does not do:** extract keywords (spans). The category and the meta-text decision only.

### Prepared (11-06, evening): the tree

- **`dm_run.py --dump-tree OUT`** writes the descent tree as JSON, with the SHA-256 of each input and its own digest
  (`3ef6fced…`).
- **Its shape:**
  - 4,711 terms under 10 facets and 122 groups;
  - 750 inner term nodes;
  - parent chains of up to 11;
  - one chunked node (`historické oblasti a státní útvary`);
  - 885 possible choices, the widest with 251 options.
- **11-05 counted 797 inner nodes.** The generated count is 750 (731 if parents stayed inside their group); the
  plan says why.
- **Tests:** 10 new ones (`tests/test_dm_tree.py`):
  - every term reachable once;
  - every choice ≤ 255 options with none lost;
  - the chunking;
  - the geographic gate;
  - wording from the prompt blocks;
  - a stable digest.

## ⚠️ Limits

- **No change during the pilot** to the service, the prompt, `MODEL_KEY`, the defaults or the record. A
  controlled-kind `decision` method in `service/api.py:_run_controlled` would be its own reviewed change after the
  pilot.
- **Facets and groups are routing levels, never a category** (P1, P2). Chunks are plumbing and are never emitted.
- **The request count per line is measured, not assumed.** TEATER branches go up to 11 levels.
- **OCR text is untrusted input.** An answer never changes the vocabulary or the record by itself.
- **Whether decision models join the D2 gold comparison is motyc's call.** #2's comment of 11-06 left it as a TODO;
  the umbrella asks him.
- **No hosted inference on archive text.**
